# PROMUEVA DATA

This repository contains a collection of anonymized datasets gathered from X (formerly Twitter) and YouTube as part of the [PROMUEVA Project](https://sites.google.com/view/promueva/english-version). We collected and analyzed more than 500,000 social media posts (mainly on X/Twitter, with two cases on YouTube) covering topics in Colombia between June 2024 and May 2026. The distribution of posts is (approximately):


| Topic                                      | Volume | Platform |
|--------------------------------------------|---------|-----------|
| Pension Reform                             | 10,000  | X         |
| COP16 Biodiversity Conference              | 10,000  | X         |
| Pegasus (surveillance software)            | 5,000   | X         |
| Deportados (deportations to Colombia)      | 10,000  | X         |
| Álvaro Uribe Trial                         | 171,500 | YouTube   |
| Gender Violence     (Univalle case)        | 1,000   | X         |
| Gender Violence     (general)              | 7,000   | X         |
| Gustavo Petro visit to Cali                | 4,500   | X         |
| Labor Referendum (labor reform)            | 5,000   | X         |
| Miguel Uribe Attempt                       | 7,500   | X         |
| Colombia Presidential Elections 2026       | 302,000 | X / YouTube  |


For each case, we combined qualitative contextualization with quantitative measures of audience stance and polarization using the MEC (Mass Event Consensus) index.

This datasets illustrates how different issues mobilize publics in distinct ways, providing empirical grounding for models of opinion dynamics and polarization. It is directly relevant to interdisciplinary research in computer science, political science, and social sciences, offering a testbed for validating theoretical models of bias, consensus, and polarization against real-world data.

If you need more details about the datasets or the PROMUEVA project, please contact the PROMUEVA Team at: promueva@googlegroups.com
